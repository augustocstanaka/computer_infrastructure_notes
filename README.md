## Conceitos Básicos de Infraestrutura de TI

A infraestrutura de TI é o conjunto de componentes necessários para operar e gerenciar ambientes corporativos de TI. Ela pode ser implantada em um sistema de computação em nuvem ou nas próprias instalações da empresa (on-premises).

Os principais componentes da infraestrutura de computadores incluem:

### 1. Hardware
O hardware abrange todos os componentes físicos de um computador ou sistema.
*   **CPU (Unidade Central de Processamento):** O cérebro do computador, responsável por executar instruções.
*   **Memória RAM:** Memória de acesso rápido e volátil usada para armazenar dados e instruções que a CPU precisa acessar imediatamente.
*   **Armazenamento (HDD/SSD):** Onde os dados são armazenados de forma persistente. SSDs (Solid State Drives) são muito mais rápidos que HDDs tradicionais.
*   **Placa-Mãe (Motherboard):** A placa de circuito principal que conecta e permite a comunicação entre todos os componentes de hardware.
*   **Servidores:** Computadores robustos projetados para fornecer serviços, dados ou recursos para outros computadores (clientes) em uma rede.

### 2. Software
O software refere-se aos programas e sistemas operacionais que gerenciam o hardware e permitem que os usuários executem tarefas.
*   **Sistemas Operacionais (SO):** O software fundamental que gerencia o hardware e os recursos do sistema (ex: Linux, Windows, macOS). O Linux é amplamente utilizado em servidores e infraestrutura em nuvem.
*   **Software de Virtualização:** Permite que múltiplos sistemas operacionais rodem simultaneamente em uma única máquina física (ex: VMware, Hyper-V, KVM).
*   **Containers:** Ambientes isolados que empacotam uma aplicação e suas dependências, garantindo que ela rode de maneira consistente em qualquer ambiente (ex: Docker).

### 3. Redes (Networking)
Componentes de rede interconectam dispositivos e permitem a comunicação e o compartilhamento de recursos.
*   **Switches:** Conectam dispositivos dentro de uma mesma rede local (LAN).
*   **Roteadores (Routers):** Conectam diferentes redes entre si, encaminhando dados entre elas (ex: conectando uma rede local à Internet).
*   **Firewalls:** Sistemas de segurança que monitoram e controlam o tráfego de rede de entrada e saída com base em regras de segurança predeterminadas.
*   **Protocolos:** Regras que determinam como os dados são transmitidos (ex: TCP/IP, HTTP/HTTPS, DNS).

### 4. Computação em Nuvem (Cloud Computing)
A entrega de serviços de computação (servidores, armazenamento, bancos de dados, redes, software) pela Internet.
*   **IaaS (Infraestrutura como Serviço):** Fornece recursos de computação virtualizados pela internet (ex: AWS EC2, Google Compute Engine).
*   **PaaS (Plataforma como Serviço):** Fornece uma plataforma para desenvolver, testar e gerenciar aplicações sem lidar com a infraestrutura subjacente.
*   **SaaS (Software como Serviço):** Entrega de aplicações de software pela internet sob demanda (ex: Google Workspace, Microsoft 365).
